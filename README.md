# Eu Também Jogo

Plataforma de jogos, atividades de aprendizagem, histórias e músicas para crianças com paralisia cerebral e outras dificuldades motoras, que comunicam pelo olhar, joystick, botão (manípulo), sopro ou sorriso.

- `index.html` — a plataforma (é a página que o GitHub Pages mostra).
- `fonte/` — código-fonte e imagens. Para gerar de novo a página: `python3 fonte/construir.py` e copiar `site/index.html` para a raiz.

Os vídeos do YouTube só funcionam na versão alojada no site (GitHub Pages).
